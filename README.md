# 🎥 Stream Fetcher - Media Downloader Web App

A clean, modern, and light-weight web application to download media streams locally using **Flask**, **HTML5/CSS3/JS**, and **yt-dlp**.

## 🚀 Features

- **Modern Glassmorphism UI:** Built with dark-mode aesthetic and smooth CSS transitions.
- **Fast Processing:** Powered by `yt-dlp` for extracting high-quality video streams.
- **Asynchronous Requests:** Uses Fetch API for real-time loading feedback without page reloads.
- **Cross-Origin Enabled:** Flask-CORS configured for seamless frontend-backend communication.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Modern Flexbox & Glassmorphism), Vanilla JavaScript
- **Backend:** Python 3, Flask framework
- **Core Library:** `yt-dlp` for video stream extraction
